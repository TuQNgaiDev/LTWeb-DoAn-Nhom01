# Thư mục kiemtra/

Lưu ảnh minh chứng kiểm thử của website và các trang cá nhân.

- Các thư mục thành viên giữ ảnh và tài liệu mô tả từ các bài trước.
- `btn5/` chỉ lưu ảnh PNG minh chứng cho bài tập nhóm 5: chức năng PHP, giao diện 360 px và kết quả Lighthouse.

Thư mục này được giữ trong kho Git vì đề bài yêu cầu ảnh minh chứng trong `kiemtra/`. Các script và tệp kết quả HTML, JSON, TXT phục vụ kiểm thử nội bộ được giữ riêng trên máy, không đưa vào kho Git.
